# Deployed server ONLY — the smallest set that serves the operator console.
#
#   python -m pip install -r requirements-deploy.txt
#
# This is deliberately NOT requirements-base.txt + requirements-web.txt. The
# deployed app never ingests imagery: PRD §9.1 puts tile ingestion, detection,
# verification and drift on the workstation, and ships the results as a JSON run
# artefact. So the free-tier image needs none of the geospatial stack — no
# rasterio/GDAL, no geopandas, no netCDF4, no xarray, no matplotlib. Leaving
# them out takes several hundred MB and minutes of build time off every deploy,
# which is what makes a free tier usable.
#
# Do NOT install this on a development machine. It is a subset: `pytest` here
# would fail on every test that touches a tile. Use requirements-base.txt +
# requirements-web.txt locally.
#
# The Dockerfile smoke-imports `ghostnet.webapp.app` right after installing
# this file, so if the server's import graph grows a dependency that is missing
# here, the image fails to build rather than crashing on first request.

# --- the server itself ---

uvicorn[standard]>=0.30

# --- data contracts and config ---
pydantic>=2.8

# --- imported by ghostnet.agents.detection, which verification imports for
