# IMPORTANT — RTX 50-series (Blackwell) is compute capability sm_120 and needs a
# CUDA 12.8+ build of PyTorch. A default `pip install torch` may pull a build

# and then fail at the first real CUDA op. Always install from the cu128 index
# and verify with `python scripts/check_machine.py`.
#
#   python -m pip install -r requirements-gpu.txt --index-url https://download.pytorch.org/whl/cu128
#
# Verified working on this workstation (2026-08-14, re-verified 2026-08-25):
#   torch 2.12.0.dev20260408+cu128, sm_120 present in torch.cuda.get_arch_list()

# This file previously named torchvision, segmentation-models-pytorch, timm,
# albumentations and tensorboard. None are installed and none are needed.
#
# The reason is specific rather than aesthetic: this machine runs a PyTorch
# *nightly* (2.12.dev+cu128), which is the build verified to carry sm_120
# kernels for the RTX 5070. torchvision and timm pin against a released torch
# ABI, so installing them risks resolving torch backwards and silently
# destroying GPU training for the one machine that can do it.
#
# The CNN detector (FR-1.4) is therefore a hand-written U-Net in
# src/ghostnet/agents/detection_cnn.py using nothing but torch — about 2 MB of
# plain PyTorch. The usual reason to want smp is a pretrained ImageNet encoder,
# and MARIDA is 11 spectral bands rather than RGB, so that transfer is weak and
# the first convolution has to be rebuilt regardless.
#
# If a future model genuinely needs them, install into a separate virtualenv
# and pin torch explicitly rather than adding them here.
